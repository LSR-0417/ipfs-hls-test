# 雙字幕規格驗證測試 (Spec. Test)

## 文件狀態

- 狀態：Kickoff baseline
- 版本：`v1`
- 性質：對應字幕 `User Story v1` 的最低送測門檻
- 對應文件：
  - [`DUAL_SUBTITLE_SRS.md`](./DUAL_SUBTITLE_SRS.md)
  - [`PLAYER_SRS.md`](./PLAYER_SRS.md)

## 1. 文件目的

本文件定義本次字幕主題的 `Spec. Test`，作為 `Developer` 開發與本地自測的最低考卷。

本版只覆蓋目前 `User Story v1` 的 Happy Path，不涵蓋：

- 慢速載入與錯誤分類
- `A/B` 主次字幕角色互換
- 惡意或破損字幕檔
- 競態、初始化容錯與其他 Edge Case

上述項目可保留在後續 `Scenario Test` 或 `Edge Test`。

## 2. 對應 User Story

1. 當影片有提供字幕檔時，播放器的 action button 要能夠選擇。
2. 有一個獨立的關閉字幕的 action button，綁定快速鍵 `C`。
3. 當影片有提供多個字幕檔時，可以選擇副字幕，副字幕縮小一定比例。
4. 允許使用者下載影片提供的字幕檔。
5. 允許使用者上傳字幕檔，且上傳後可以作為主或副字幕使用。
6. 如果有字幕檔的話，自動按照瀏覽器語系選擇，預設為開啟英文字幕。
7. 控制列要有一顆獨立的 action button，可以切換主字幕 / 副字幕的上下角色。

## 3. 規格解讀基線

為避免實作歧義，本版 `Spec. Test` 固定採用以下解讀：

- 首次載入且本機沒有既有字幕偏好時，只要存在可用字幕，系統就自動開啟字幕。
- 主字幕優先依 `navigator.languages` / `navigator.language` 選擇最接近語系。
- 若瀏覽器語系沒有任何匹配，則 fallback 到英文字幕。
- 若仍無英文字幕，則 fallback 到第一條可用字幕。
- 獨立的字幕總開關按鈕只控制整體字幕顯示，不改變目前已選的主字幕 / 副字幕語言。
- 主字幕與副字幕不得為同一語言。

## 4. 測試前置條件

### 4.1 測試資產

至少準備以下三種測試影片資料：

- `CID-SUB-EN`
  - 含影片與單一遠端字幕：`en`
- `CID-SUB-MULTI`
  - 含影片與多個遠端字幕：`en`、`zh-TW`
  - 若要驗證更完整的語系匹配，可額外放入 `ja`
- `CID-NO-SUB`
  - 含影片但不含遠端字幕

### 4.2 本機測試檔

至少準備以下本機字幕檔：

- `local-primary.srt`
  - 語系：`zh-TW`
- `local-secondary.vtt`
  - 語系：`en`

### 4.3 瀏覽器前置

- 測試「首次載入」前，需先清除 `localStorage` 中的字幕偏好。
- 至少驗證以下兩組瀏覽器語系：
  - `['zh-TW', 'en-US']`
  - `['fr-FR']`

## 6. 規格驗證案例

### Spec-SUB-001 主字幕入口與主字幕選擇

**目的**

驗證影片存在遠端字幕時，播放器提供可操作的主字幕入口，且使用者可切換主字幕。

**前置條件**

- 載入 `CID-SUB-MULTI`

**步驟**

1. 進入播放器頁面並等待影片與字幕清單完成初始載入。
2. 檢查播放器控制列是否存在主字幕 action button。
3. 點開主字幕選單。
4. 在選單中改選另一個可用語言作為主字幕。

**預期結果**

1. 主字幕 action button 可見且可操作。
2. 主字幕選單至少包含：
   - `關閉主字幕`
   - 所有可用字幕語言
3. 目前主字幕在選單中有明確標示。
4. 改選後，主字幕立即切換到新語言。
5. 切換主字幕不會重建整個 player。

### Spec-SUB-002 獨立字幕總開關與快捷鍵 `C`

**目的**

驗證獨立字幕總開關與鍵盤快捷鍵 `C` 只切換字幕顯示狀態，不改變已選語言。

**前置條件**

- 載入 `CID-SUB-MULTI`
- 已有有效主字幕，且可額外設定一條副字幕

**步驟**

1. 將主字幕設為 `zh-TW`。
2. 將副字幕設為 `en`。
3. 點擊獨立的字幕總開關 action button。
4. 確認畫面字幕全部關閉。
5. 按下鍵盤 `C`。

**預期結果**

1. 獨立字幕總開關按鈕存在，且與主字幕選擇入口分離。
2. 關閉時，主字幕與副字幕都一起消失。
3. 關閉時，不清空已保存的 `primaryLang` / `secondaryLang`。
4. 按下 `C` 後，字幕重新開啟。
5. 重新開啟後，主字幕仍為 `zh-TW`，副字幕仍為 `en`。

### Spec-SUB-003 副字幕選擇與視覺層級

**目的**

驗證多字幕情境下可選副字幕，且副字幕顯示在主字幕上方並縮小。

**前置條件**

- 載入 `CID-SUB-MULTI`
- 主字幕已設為 `zh-TW`

**步驟**

1. 開啟 `SubtitleDialog`。
2. 將副字幕設為 `en`。
3. 觀察字幕實際渲染。
4. 嘗試將主字幕與副字幕設為相同語言。

**預期結果**

1. `SubtitleDialog` 可選擇副字幕。
2. 副字幕選定後立即生效。
3. 主字幕顯示在下，副字幕顯示在上。
4. 副字幕尺寸明顯小於主字幕，目標比例為主字幕的 `70%~80%`，目前基線為 `76%`。
5. 系統禁止主字幕與副字幕同語言；若使用者嘗試重複，系統會自動避免重複組合。

### Spec-SUB-004 下載遠端字幕

**目的**

驗證使用者可以下載影片原本提供的字幕檔。

**前置條件**

- 載入 `CID-SUB-MULTI`

**步驟**

1. 開啟 `SubtitleDialog`。
2. 對任一遠端字幕執行下載操作。

**預期結果**

1. `SubtitleDialog` 內可對遠端字幕看到下載入口。
2. 下載操作成功觸發瀏覽器下載。
3. 下載檔名穩定且對應所選字幕語言。
4. 下載遠端字幕不依賴瀏覽器既有快取才可成功。

### Spec-SUB-005 上傳字幕並作為主字幕或副字幕

**目的**

驗證本機上傳字幕可立即加入可用清單，並可被指定為主字幕或副字幕。

**前置條件**

- 載入 `CID-SUB-EN`
- 目前主字幕為遠端 `en`

**步驟**

1. 開啟 `SubtitleDialog`。
2. 上傳 `local-primary.srt`。
3. 確認新字幕出現在可用字幕清單。
4. 將上傳字幕設為副字幕。
5. 再將上傳字幕改設為主字幕。

**預期結果**

1. 上傳接受 `.srt` / `.vtt`。
2. 上傳完成後，字幕立即可用，無需重新整理頁面。
3. 上傳字幕可被指定為副字幕。
4. 上傳字幕也可被切換成主字幕。
5. 當影片原本沒有主字幕時，首次上傳的字幕可自動成為主字幕。

### Spec-SUB-006 首次載入的語系自動選擇與英文 fallback

**目的**

驗證首次載入時，系統會自動開啟字幕並依瀏覽器語系選擇主字幕；沒有匹配時 fallback 到英文。

**前置條件**

- 清除字幕偏好 `localStorage`

**步驟 A：瀏覽器語系命中**

1. 將瀏覽器語系設為 `['zh-TW', 'en-US']`。
2. 載入 `CID-SUB-MULTI`。

**預期結果 A**

1. 首次載入時字幕自動開啟。
2. 主字幕自動選為 `zh-TW`。

**步驟 B：瀏覽器語系未命中**

1. 再次清除字幕偏好。
2. 將瀏覽器語系設為 `['fr-FR']`。
3. 載入 `CID-SUB-MULTI`。

**預期結果 B**

1. 首次載入時字幕自動開啟。
2. 因沒有法文字幕，主字幕 fallback 到 `en`。
3. 若測試資料沒有英文字幕，則 fallback 到第一條可用字幕。

### Spec-SUB-007 主字幕 / 副字幕交換按鈕

**目的**

驗證控制列存在獨立的主字幕 / 副字幕交換 action button，且按下後只交換上下角色，不改變字幕總開關狀態。

**前置條件**

- 載入 `CID-SUB-MULTI`
- 主字幕設為 `zh-TW`
- 副字幕設為 `en`

**步驟**

1. 確認控制列出現 `A/B` 交換按鈕。
2. 按下交換按鈕一次。
3. 觀察主字幕 / 副字幕的角色與畫面位置。
4. 再按一次交換回原本配置。

**預期結果**

1. 只有同時存在主字幕與副字幕時，才會顯示 `A/B` 交換按鈕。
2. 按下後，原本的副字幕變成主字幕，原本的主字幕變成副字幕。
3. 交換後字幕總開關仍維持開啟。
4. 交換只改變角色與畫面上下關係，不移除任何可用字幕資源。
